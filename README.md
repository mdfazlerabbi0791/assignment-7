1. Project name: 
--------
BazarDor — Daily Market Price Tracker

2. Short description: 
--------

BazarDor is a Bangla-language web application that helps users explore daily market prices of essential products in one place. Users can browse product categories, view product prices, track price changes, and find relevant market information through a simple and responsive interface.

3. Technologies used:
--------

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Better Auth
- MongoDB
- REST API
- Lucide React
- Git and GitHub

4. 5 key features of the project:
--------

1. **Daily Market Prices:** Displays essential products and their current listed prices.

2. **Product Categories:** Allows users to browse products by category.

3. **Price Change Tracking:** Shows price changes and percentage variations to help users understand market trends.

4. **User Authentication:** Provides sign-up and sign-in functionality using Better Auth.

5. **Responsive User Interface:** Offers a clean, Bengali-language interface that works across mobile, tablet, and desktop devices.
